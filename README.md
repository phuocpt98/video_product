# video_product

Studio AI biến truyện chữ tiếng Việt thành video YouTube, clip TikTok và thumbnail.

- Lối vào và bản đồ thư mục: [CLAUDE.md](CLAUDE.md)
- Mục lục tài liệu: [docs/README.md](docs/README.md)
- Cài trên máy mới: [docs/setup.md](docs/setup.md) (`bash scripts/setup.sh`)

Repo chỉ chứa cấu trúc, quy tắc, code tự viết và thư viện hình (diễn viên, bộ phận, đạo cụ, cảnh). Không chứa dữ liệu từng truyện, video thành phẩm, model AI hay repo tham khảo trong `tool/`.
